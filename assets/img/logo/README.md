# Aset Logo Sistem Informasi Perpustakaan

Folder ini memuat seluruh aset identitas visual dan logo dalam format vektor SVG dan raster PNG untuk website Sistem Informasi Perpustakaan.

## Struktur Aset

- **`logo-symbol.svg`**: Simbol warna utama (Navy & Cyan) untuk navbar dan komponen utama website.
- **`logo-symbol-small.svg`**: Simbol optimal untuk ukuran kecil (16–32 px).
- **`logo-symbol-favicon.svg`**: Favicon vektor SVG modern untuk tab peramban.
- **`favicon.ico`**: Favicon format ICO untuk kompatibilitas peramban legacy.
- **`logo-symbol-black.svg`**: Versi satu warna hitam.
- **`logo-symbol-white.svg`**: Versi satu warna putih untuk latar gelap / footer.
- **`logo-symbol-mono-1a2c4a.svg`**: Versi satu warna brand navy `#1a2c4a`.
- **`logo-horizontal.svg`**: Lockup horizontal untuk dokumen dan halaman terang.
- **`logo-horizontal-dark.svg`**: Lockup horizontal untuk halaman gelap.
- **`logo-app-icon.svg`**: Master SVG ikon aplikasi berbingkai squircle.
- **`apple-touch-icon.png`**: Ikon web mobile iOS (180x180).
- **`pwa-icon-192.png` & `pwa-icon-512.png`**: Ikon aplikasi web progresif (PWA).

Panduan lengkap mengenai filosofi, palet warna, tipografi, dan aturan penggunaan dapat dibaca pada:
[`docs/brand-guidelines.md`](../../docs/brand-guidelines.md).
